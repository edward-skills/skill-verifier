# v0.3.4 - Capability-based host adaptation

This documentation and template update separates inspecting an exported skill, running the verifier in a host, and driving that host as a comparison task worker. It adds a pending harness evidence worksheet and documentation-based adaptation notes for Hermes, pi, SpaceX Grok Bot and Meta Muse.

The worksheet is not executable and cannot grant a passing gate. Existing runner behavior, isolation policy and vendor adapter examples are unchanged. Grok Build and Muse Code are explicitly separate from the personal cloud agents.

Installation, explicit loading, offline execution, native activation and real tasks need their own evidence. This release adds no model calls, native activation acceptance or new enforced backend.

Author validation on macOS: repository checks passed; all 97 offline regression tests passed without skips, including the native boundary and copied-interpreter checks. No model calls were made. The earlier independent QA remains scoped to its frozen release.
