# v0.3.3 — Document-only routing and explicit verdict scope

Skills without supported helpers previously fell through to CLI-oriented code drafts. `offline-init --profile auto` now selects disabled document-review cases and records `source-review-only`. Explicit profiles remain unchanged, and targets with helpers retain domain selection. No target commands run during initialization.

Offline results add `whole_skill_verdict: not-assessed`, and reports state that separation immediately after the local gate. A passing source audit or helper test does not establish generated-task quality, native activation or cross-harness behavior. Existing gate logic, failure records, manual-review binding and isolation requirements are unchanged.

Author macOS offline regression: 97 passed, zero skipped. Prior independent QA applies to the frozen 0.3.2 release. Real-model validation, native activation, cross-harness tasks and Linux enforced isolation remain unverified.
